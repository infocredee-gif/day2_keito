The "read on" link: label plus a trailing Material glyph, hovering to orange over 300ms.

```jsx
<ArrowLink href="/development">研究開発ストーリーへ</ArrowLink>
<ArrowLink href="/about" glyph="chevron_right">会社概要</ArrowLink>
```

Use `arrow_forward` in body/section copy and `chevron_right` inside menu and drawer lists. Never underline it.
