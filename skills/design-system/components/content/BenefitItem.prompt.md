Benefit cell for the OEM merits grid — uses the brand's own SVG line illustrations, never a drawn icon.

```jsx
<BenefitItem icon="assets/illustrations/icon-cost.svg" title="ローコストで新商品が完成"
  body="一貫製造によりクライアント様には仕入しやすい価格で提供します。" />
```

Three per row on desktop, centred, no card chrome.

Note: the source SVGs reference undefined `.st0`/`.st1` classes and therefore render as solid black shapes. Until coloured originals arrive, prefer text-only benefit cells in polished work.
