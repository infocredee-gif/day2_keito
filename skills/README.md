# skills/

`style-system-web-builder` スキルが参照する素材置き場。

| フォルダ | 中身 | 状態 |
|---|---|---|
| `design-system/` | 自作のデザインシステム（色・文字・余白・部品・アセット） | 設置済み |
| `style-vault/` | デザイン見本集（スタイルごとに `DESIGN.md` と `index.html`） | **未設置** — ここに追加してください |

`style-vault/` は以下の形を想定しています。

```
skills/style-vault/
├── <slug-1>/
│   ├── DESIGN.md
│   └── index.html
└── <slug-2>/
    ├── DESIGN.md
    └── index.html
```
